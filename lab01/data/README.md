# Локальные корпуса

Файлы данных исключены из Git через `lab01/.gitignore`. В этой рабочей копии они
уже перенесены из готовой `laba01`; ноутбук запускается без обращения к старой папке.

| Файл | Назначение | Токенов |
|---|---|---:|
| `corpus.txt` | Очищенный текст основной части, токенизация в ноутбуке | 173 006 |
| `author_dostoevsky_tokens.txt` | Токены EPUB Достоевского для Байеса | 173 138 |
| `author_tolstoy_tokens.txt` | Токены EPUB Толстого для Байеса | 271 303 |

Источники: [«Преступление и наказание», Викитека](https://ru.wikisource.org/wiki/Преступление_и_наказание_(Достоевский)),
[«Анна Каренина», Викитека](https://ru.wikisource.org/wiki/Анна_Каренина_(Толстой)).
Текст и оформление экспорта могут изменяться: для точного повторения чисел нужна
та же локальная редакция, которая использовалась в исходной работе.

Для восстановления основной части положите TXT романа Достоевского в `lab01/data/`,
например под именем `dostoevsky.txt`, и из корня репозитория выполните:

```powershell
python lab01/prepare_corpus.py lab01/data/dostoevsky.txt
Copy-Item lab01/data/dostoevsky_clean.txt lab01/data/corpus.txt
```

Скрипт выделяет текст от начала первой главы до конца эпилога, удаляет сноски
и заголовки, сохраняет очищенный TXT и токены. На исходной редакции получается
173 006 токенов; ноутбук повторяет токенизацию регулярным выражением `[а-яёa-z]+`.

Для бонуса с Байесом экспортируйте две книги в EPUB и положите их в `lab01/data/`
под именами `author_dostoevsky.epub` и `author_tolstoy.epub`:

```powershell
python lab01/prepare_epub_tokens.py lab01/data/author_dostoevsky.epub lab01/data/author_tolstoy.epub
```

Скрипт обходит главы в порядке EPUB spine, удаляет служебные элементы и создаёт
`author_dostoevsky_tokens.txt` и `author_tolstoy_tokens.txt`. Он поддерживает
имена глав `chapterN.xhtml` и `cN_*Glava_*.xhtml`, использованные в исходных экспортах.
Другой EPUB с иной структурой может потребовать изменения фильтра имён глав.
